# Contributing and AI-assisted customization

Ideas, bug reports and personal-use forks are welcome. Read LICENSE before using or distributing this project. Commercial use needs written permission.

- Keep changes focused and identify the platform. Test the Python backend, frontend and Android build as applicable.
- Never commit recordings, credentials, private keys, device IPs/MACs/serials, pairing databases, user profiles or raw diagnostics.
- Preserve profile data and unknown future preference fields. Increment Android versionCode for each changed distributed APK; keep signing identity stable for in-place updates.
- Distinguish simulated UI checks, decoder checks, post-output recordings and actual overnight listening. Do not claim a test eliminated every stutter.
- Describe AI-assisted changes and verify generated code. Preserve real HTML controls, accessibility, low-resource behavior and existing playback.
- Contributions must be yours to share. Submitting a contribution grants the maintainer a non-exclusive, worldwide, perpetual right to use, modify and distribute it under this project's current personal-use license and separately authorized commercial terms. You retain your copyright. Do not submit third-party code under incompatible terms.

For bugs include version, platform, output type, timing and reproduction steps. Redact identifying details from logs and screenshots.
