# Security

This alpha is for a trusted LAN only; do not expose port8080 to the public internet. HTTP control and discovery are not authenticated encrypted sessions. User profiles are convenience preferences, not accounts or privacy barriers.

Never post credentials, audio recordings, pairing stores, private keys or unredacted diagnostic exports. For a suspected vulnerability, first open an issue requesting a private contact channel without including exploit details or secrets. No hosted/cloud account is required for ordinary use.
